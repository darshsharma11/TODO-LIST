A brutalist-style, responsive to-do list built with HTML, CSS, and vanilla JavaScript.

No frameworks. No backend. No database.

Features
Add tasks with optional due dates
Mark tasks as complete
Edit existing tasks
Delete tasks
Clear completed tasks
Filter tasks by:
All
Today
Active
Done
Overdue
List view
Calendar view
Monthly calendar navigation
Overdue and due-today indicators
Task statistics
Responsive design for desktop and mobile
Keyboard shortcuts
Data saved automatically in the browser using localStorage
Keyboard Shortcuts
N — Focus the new-task input
Enter — Add a task / save an edit
Esc — Close the calendar dialog or cancel editing
How It Works

This is a completely client-side application.

Tasks are stored in the browser using localStorage, so there is no server or database involved. Your tasks remain available in the same browser/device until the browser's site data is cleared.
